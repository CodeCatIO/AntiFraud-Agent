## 三、各模块功能说明

### 3.1 用户与权限模块

| 组件 | 功能 | 关键技术 |
|------|------|----------|
| UserController | 登录、注册、登出、CRUD、分页、导入导出Excel | JWT + Redis黑名单 |
| UserServiceImpl | 登录验证、密码加密、角色菜单关联 | BCrypt + MD5兼容迁移 |
| RoleController | 角色管理、角色菜单分配 | RBAC权限模型 |
| MenuController | 菜单树形结构管理 | 递归构建菜单树 |
| JwtInterceptor | Token校验拦截器 | Auth0 java-jwt库 |
| TokenUtils | Token生成/验证/黑名单 | HMAC256算法 + Redis TTL |

**核心特性：**
- 新用户密码使用 **BCrypt** 加密，老用户MD5密码首次登录自动迁移为BCrypt
- Token 黑名单机制：登出时将Token加入Redis，设置过期时间等于Token剩余有效期
- 登录限流：60秒内最多10次（`@RateLimit`注解实现）
- 注册限流：3600秒内最多5次

### 3.2 智能检测模块（核心）

| 检测类型 | 接口路径 | 调用方式 | Python模块 |
|----------|----------|----------|------------|
| 文本检测 | POST /detect/text | AiServiceClient (HTTP) | anti_fraud_text.py |
| 语音检测 | POST /detect/voice | AiServiceClient (HTTP) | anti_fraud_voice.py |
| 图像检测 | POST /detect/image | AiServiceClient (HTTP) | anti_fraud_image.py |
| 综合评估 | POST /detect/composite | AiServiceClient (HTTP) | risk_assessment.py |
| 记录查询 | GET /detect/records | 直连数据库 | - |
| 统计数据 | GET /detect/stats | 直连数据库 | - |

**调用流程：**
```
前端 → DetectController → AiServiceClient → Flask微服务 → Python检测模块
        (保存记录到DB)    (HTTP REST)        (路由分发)      (核心算法)
```

### 3.3 模型训练与批量预测模块

## 六、Python脚本核心算法逻辑

### 6.1 文本诈骗检测 (anti_fraud_text.py)

**算法：** 规则引擎 + 关键词匹配 + 正则模式匹配

```
风险评分 = 高风险关键词数×15 + 中风险关键词数×8 + 句式匹配得分 + 紧急程度分 + 链接/电话分
```

**检测维度：**
1. **关键词匹配**：高风险词28个（转账、验证码、公检法、刷单等，每个+15分），中风险词30个（优惠、加微信、兼职等，每个+8分）
2. **诈骗句式识别**：9种正则模式（账户异常、诱导点击链接、诱导转账、中奖诈骗、冒充公检法等，20-35分/个）
3. **紧急程度分析**：感叹号≥3个 +10分
4. **链接检测**：包含URL +10分
5. **电话号码检测**：包含手机号 +5分

**风险等级：** ≥70高风险 / ≥40中风险 / <40低风险

### 6.2 图像伪造检测 (anti_fraud_image.py)

**算法：** 多维度特征分析 + ELA误差分析 + 降级策略

**检测维度（7个）：**
1. **元数据检测**：AI生成工具标识(+25)、缺少EXIF信息(+10)
2. **尺寸分析**：正方形高分辨率(+8)，AI生成常见尺寸
3. **色彩分布分析**：色彩标准差<30 (+15)，AI生成图色彩过于均匀
4. **噪声模式分析**：噪声水平<2 (+20)，AI生成图过度平滑
5. **边缘锐度分析**：边缘比例>0.15 (+10)，AI增强特征
6. **肤色/人脸检测**：检测到人物区域(+5)
7. **ELA误差分析**：
   - ELA>15：明显编辑痕迹(+25)
   - ELA>8：轻微编辑痕迹(+12)
   - ELA<1：极低误差，AI生成特征(+10)

**降级策略：** OpenCV可用时用OpenCV完整分析，否则降级到PIL，再降级返回基础评分。

### 6.3 语音伪造检测 (anti_fraud_voice.py)

**算法：** 声学特征提取 + 模式识别（librosa）

**核心特征：**
- MFCC（梅尔频率倒谱系数）均值/方差
- 频谱质心 (spectral centroid)
- 过零率 (zero crossing rate)
- 基频检测

**降级策略：** librosa不可用时基于文件大小做启发式判断。

### 6.4 综合风险评估 (risk_assessment.py)

**算法：** 加权平均法

```
综合风险分 = 文本分×0.3 + 语音分×0.35 + 图像分×0.35
```

**权重配置：** 文本30%、语音35%、图像35%（语音和图像权重更高）

**风险等级：** 0无风险 / <30低风险 / <70中风险 / ≥70高风险

### 6.5 区块链存证 (blockchain_cert.py)

**算法：** SHA-256哈希 + 链式结构（模拟区块链）

**区块结构：**
```python
{
    "index": 区块索引,
    "timestamp": 时间戳,
    "data": 存证内容,
    "hash": SHA-256(数据),
    "previous_hash": 前一区块哈希
}
```

**存储方式：** 本地JSON文件 (`blockchain_data/chain.json`)，非真实分布式区块链。

### 6.6 数字水印 (watermark.py)

**算法：** LSB（最低有效位）隐写术

**嵌入流程：**
1. 文本 → UTF-8编码 → 二进制位流
2. 前32位存储文本长度信息
3. 逐像素逐通道替换RGB最低位为水印位
4. 保存为PNG格式（无损压缩）

**提取流程：**
1. 读取图片所有像素RGB最低位
2. 前32位解析为文本长度
3. 按长度提取后续位并解码为UTF-8文本

## 八、关键设计亮点与注意事项

### 8.1 设计亮点

1. **双模式Python集成**：新功能用HTTP微服务（AiServiceClient），旧功能保留进程调用（PyProcessExecutor），渐进式迁移
2. **熔断器/降级模式**：AiServiceClient在AI服务不可用时返回降级结果，不阻塞主流程
3. **密码平滑迁移**：BCrypt + MD5智能匹配，老用户无感升级
4. **Token黑名单**：Redis + TTL实现真正的登出功能
5. **AOP切面编程**：限流和操作日志通过注解实现，业务代码无侵入
6. **Redis计数器限流**：固定窗口算法，支持按用户或按IP限流

### 8.2 注意事项 / 待改进

1. **两种Python调用方式并存**：训练/预测/区块链/水印用进程调用，检测用HTTP微服务，架构不统一
2. **区块链是模拟实现**：基于本地JSON文件，非真实区块链网络
3. **AI检测是规则引擎**：文本检测主要靠关键词和正则，非深度学习模型
4. **代码拼写问题**：`pythonTrianCode` 应为 `pythonTrainCode`（保留兼容）
5. **CORS配置过宽**：`allowedOrigin("*")` 生产环境应限制域名
6. **部分接口鉴权缺失**：InterceptorConfig中排除了较多路径
