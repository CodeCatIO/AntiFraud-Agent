### 添加新测试的规范

1. 测试类命名：`被测类名 + Test`
2. 测试方法命名：`test + 场景 + 预期结果`
3. 每个测试用一个 `@DisplayName` 中英文说明
4. 使用 `@SpringBootTest` 做集成测试，纯单元测试不用
5. Mock外部依赖（AI服务、第三方API等）
