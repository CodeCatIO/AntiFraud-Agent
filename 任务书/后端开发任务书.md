## 四、接口规范

### 统一响应格式
```json
{
  "code": "200",
  "msg": "",
  "data": {}
}
```

| code | 含义 |
|------|------|
| 200 | 成功 |
| 401 | 未认证/Token无效 |
| 403 | 无权限 |
| 600 | 业务异常 |

### 认证方式
- 请求头：`token: <jwt-token>`
- 登录接口返回 token，前端存储后所有请求带上

### 接口文档
- Swagger UI：http://localhost:9090/swagger-ui/index.html
- 后端新增接口必须加 Swagger 注解

## 五、开发规范

### 代码规范
- 包名：`com.cucn.springboot.*`
- 类名：大驼峰 PascalCase
- 方法名/变量名：小驼峰 camelCase
- 常量：全大写下划线分隔 UPPER_SNAKE_CASE
- 每个类/重要方法必须有 Javadoc 注释

### Git 提交规范
```
feat: 新功能
fix: 修复bug
docs: 文档更新
refactor: 重构
test: 测试相关
chore: 构建/工具配置
```

### 分支策略
- `master` — 主分支，稳定版本
- `dev` — 开发分支
- `feature/xxx` — 功能分支，开发完成后合入dev
