# AI算法开发任务书

> **项目**：AI反诈骗检测系统（毕业设计）
> **岗位**：AI算法工程师
> **技术栈**：Python + PyTorch + scikit-learn + jieba + librosa + OpenCV + Flask
> **协作方式**：算法独立开发，通过 Flask 微服务对接后端，接口先行

---

## 一、职责范围

负责项目 AI 算法核心，包括：
- 文本诈骗检测算法
- 语音诈骗检测算法
- 图像诈骗检测算法
- 综合风险评估模型
- 数据集收集与预处理
- 模型训练、调优与评估
- 算法实验对比与分析
- Flask 微服务接口维护

> **核心原则**：先有 baseline，再做提升，最后实验对比证明效果。

---

## 二、项目现状

### 当前算法实现

| 模块 | 当前实现 | 技术深度 | 目标 |
|------|---------|---------|------|
| 文本检测 | 关键词匹配 + 正则 + 朴素贝叶斯 | ⭐⭐ 规则+传统ML | ⭐⭐⭐⭐⭐ BERT/ERNIE 深度学习 |
| 语音检测 | MFCC + 启发式阈值判断 | ⭐⭐ 传统方法 | ⭐⭐⭐⭐ CNN/LSTM 深度模型 |
| 图像检测 | ELA + 噪声分析 + PIL | ⭐⭐ 传统CV | ⭐⭐⭐⭐ ResNet/EfficientNet |
| 综合评估 | 加权求和 | ⭐ 简单加权 | ⭐⭐⭐ 注意力机制/决策融合 |
| 区块链 | SHA-256 + JSON链 | ⭐⭐ 模拟实现 | ⭐⭐⭐ 保持，写清楚原理 |
| 数字水印 | LSB隐写术 | ⭐⭐⭐ 经典算法 | ⭐⭐⭐ 保持，补充鲁棒性测试 |

### 服务架构
- AI 算法以 Flask HTTP 微服务形式运行
- 后端通过 HTTP 调用 AI 服务接口
- 代码位置：`ai-service/` 目录
- 服务入口：`ai-service/flask_app/app.py`
- 运行地址：http://localhost:5000

## 三、任务清单（按优先级）

### 🔴 P0：环境搭建 + 数据集准备（第1-2周）

#### 任务1：开发环境搭建

**要装的工具：**
- Python 3.9+（推荐 Anaconda 管理环境）
- PyTorch（推荐）或 TensorFlow
- transformers（HuggingFace 预训练模型）
- scikit-learn（模型评估、数据集划分）
- pandas / numpy / matplotlib（数据处理 + 画图）
- jieba（中文分词）
- librosa（语音处理）
- OpenCV / Pillow（图像处理）
- Flask（HTTP服务）

**环境搭建命令：**
```bash
conda create -n anti-fraud python=3.10
conda activate anti-fraud
pip install torch transformers scikit-learn pandas matplotlib jieba librosa opencv-python flask
```

**验收标准：**
- 能正常启动 Flask 服务
- `http://localhost:5000/api/health` 返回 ok
- 能成功加载示例模型并做一次预测

#### 任务2：数据集收集与预处理

这是**最关键也最耗时**的一步，越早开始越好。

##### 文本检测数据集

| 数据集 | 说明 | 来源建议 |
|--------|------|---------|
| 诈骗短信数据集 | 正负样本（诈骗vs正常） | 天池/Kaggle 公开数据集、网络收集 |
| 中文垃圾短信数据集 | 可作为诈骗检测的替代 | 天池、GitHub 开源数据集 |
| 自标注数据 | 补充特定场景的诈骗样本 | 从诈骗话术模板、社交平台收集 |

**最低要求：** 5000条以上，正负样本比例约 1:1

**数据预处理：**
- 去重、去噪
- 中文分词（jieba）
- 文本长度统计
- 划分训练集/验证集/测试集（7:2:1）

##### 语音检测数据集

| 数据集 | 说明 | 来源建议 |
|--------|------|---------|
| 诈骗电话语音 | 诈骗录音样本 | 公开数据集、模拟录制 |
| 正常语音 | 日常对话录音 | 公开语音数据集（如AISHELL） |

**最低要求：** 各类型不少于 500 条，总时长 10 小时以上

**数据预处理：**
- 统一采样率（16kHz 或 22.05kHz）
- 统一声道（单声道）
- 提取 MFCC 特征
- 数据增强（加噪、变速、变调）

##### 图像检测数据集

| 数据集 | 说明 | 来源建议 |
|--------|------|---------|
| 诈骗截图 | 诈骗信息截图（短信、社交软件） | 网络收集、自标注 |
| 正常图片 | 普通截图/照片 | 公开数据集 |
| 篡改图像 | PS篡改的图片 | CASIA、IMD 等公开数据集 |

**最低要求：** 正负样本各 2000 张以上

**数据预处理：**
- 统一尺寸（如 224x224）
- 归一化
- 数据增强（翻转、裁剪、加噪）

**验收标准：**
- 三个数据集都准备好，格式统一
- 有数据统计报告（样本数、分布、示例）
- 数据预处理脚本可复现

### 🟠 P1：文本检测算法升级（第3-5周）

#### 任务3：传统机器学习 baseline

**做什么：**
- 实现 TF-IDF + 朴素贝叶斯 / SVM / 随机森林
- 做 ablation study（不同特征、不同模型对比）
- 输出混淆矩阵、准确率、精确率、召回率、F1值

**验收标准：**
- 准确率 ≥ 85%
- 有完整的实验结果图表

#### 任务4：深度学习模型

**做什么：**
- 基于 BERT / ERNIE / RoBERTa 等预训练模型微调
- 对比不同预训练模型的效果
- 尝试 TextCNN / BiLSTM / Attention 等结构
- 做模型压缩/优化（可选）

**验收标准：**
- 准确率 ≥ 92%
- 比传统方法有明显提升（≥5%）
- 有实验对比表格和分析

---

### 🟡 P2：语音 + 图像检测（第6-9周）

#### 任务5：语音诈骗检测

**做什么：**
- baseline：MFCC + GMM / SVM
- 进阶：CNN（如1D-CNN on MFCC）或 LSTM
- 可选：预训练语音模型（如 Wav2Vec2）
- 输出：二分类（诈骗/正常）+ 置信度

**验收标准：**
- 准确率 ≥ 80%
- 有特征可视化（MFCC图、频谱图）

#### 任务6：图像诈骗检测

**做什么：**
- baseline：ELA + 传统特征 + SVM
- 进阶：ResNet / EfficientNet 微调
- 可选：多任务学习（同时做真伪判断 + 风险等级）
- 输出：二分类（真伪）+ 风险等级 + OCR文字

**验收标准：**
- 真伪检测准确率 ≥ 85%
- 有类激活图（CAM）可视化

---

### 🟢 P3：综合评估 + 实验对比（第10-12周）

#### 任务7：综合风险评估模型

**做什么：**
- 设计多模态融合策略
  - 早期融合（特征拼接）
  - 晚期融合（投票/加权）
  - 注意力融合（可选）
- 对比不同融合策略的效果
- 输出综合风险分数（0-100）和等级

**验收标准：**
- 综合评估比单模态效果好
- 有融合策略对比分析

#### 任务8：实验对比与论文素材

**做什么：**
- 整理所有实验结果
- 制作对比表格和图表
- 写实验分析（为什么这个方法好、失败原因分析）
- 准备论文中的算法章节素材

**验收标准：**
- 完整的实验报告
- 所有图表清晰可用于论文

### 🔵 P4：优化 + 部署（第13-14周）

## 四、API 接口规范

### AI 服务接口

所有接口都在 Flask 服务中，基础路径：`http://localhost:5000/api`

| 接口 | 方法 | 说明 |
|------|------|------|
| `/health` | GET | 健康检查 |
| `/detect/text` | POST | 文本检测 |
| `/detect/voice` | POST | 语音检测 |
| `/detect/image` | POST | 图像检测 |
| `/risk/assess` | POST | 综合风险评估 |
| `/blockchain/cert` | POST | 区块链存证 |
| `/watermark/embed` | POST | 嵌入水印 |
| `/watermark/extract` | POST | 提取水印 |

### 新增算法接口流程

1. 在 `ai-service/` 下写好算法模块
2. 在 `ai-service/flask_app/app.py` 中添加路由
3. 用 Postman 或 curl 测试接口
4. 通知后端开发者添加对应的客户端调用

### 响应格式示例

```json
{
  "status": "success",
  "data": {
    "risk_score": 85,
    "risk_level": "高风险",
    "is_fraud": true,
    "confidence": 0.92,
    "details": {
      "suspicious_keywords": ["中奖", "转账", "验证码"],
      "fraud_type": "中奖诈骗",
      "analysis": "文本中包含典型中奖诈骗特征..."
    }
  }
}
```

## 五、开发规范

### 代码规范
- 使用 Python 3.9+ 语法
- 遵循 PEP 8 规范
- 函数和类必须有 docstring
- 关键算法加详细注释

### 目录规范
```
ai-service/
├── flask_app/          # Flask服务
│   └── app.py          # 入口文件
├── models/             # 训练好的模型（.gitignore）
├── data/               # 数据集（.gitignore 大数据集）
├── anti_fraud_text.py  # 文本检测
├── anti_fraud_voice.py # 语音检测
├── anti_fraud_image.py # 图像检测
├── risk_assessment.py  # 风险评估
├── model.py            # 模型定义
├── train_*.py          # 训练脚本
└── requirements.txt    # 依赖清单
```

### Git 提交规范
```
feat: 新算法/新功能
fix: 修复bug
docs: 文档更新
refactor: 代码重构
perf: 性能优化
experiment: 实验相关
data: 数据集相关
```

### 实验规范
- 每次实验记录超参数和结果
- 保存训练日志和模型checkpoint
- 图表统一风格，字体清晰
- 随机种子固定，保证可复现
